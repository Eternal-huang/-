# 团队论文 PDF 库

[点击上传 PDF](https://github.com/Eternal-huang/-/upload/main/papers)

1. 登录有仓库写入权限的 GitHub 账号，选择或拖入 PDF。
2. 建议文件名：`年份_第一作者_简短标题.pdf`。文件名会成为网站上的论文标题。
3. 点击 Commit changes；若提交到新分支，需要合并到 main 后才会发布。
4. 等待 Publish project workspace 成功，回到 GitHub Pages 的“论文阅读”，选择“团队上传”或点击“刷新论文库”。

单文件不超过 25 MiB；可多选。构建脚本只收录具有 PDF 文件头的 `.pdf` 文件，跳过符号链接、其他格式和超限文件，并在 Actions 输出原因。目录及子目录均支持。

上传论文会在正式网站公开展示，请上传可以公开分享的版本；仅有访问权不一定有公开再分发权。不能分享全文时，在阅读笔记中填写 DOI 或来源链接即可。

删除或替换文件后，下一次成功部署会重新生成目录。网站不会自动推断作者、发表年份或摘要，也不会将上传文件认定为已同行评审论文。阅读状态和笔记仍是本机草稿，正式提交 Issue 才会共享。

负责人预览网站不会随 GitHub 上传自动同步文件，以 GitHub Pages 正式网站为准。
